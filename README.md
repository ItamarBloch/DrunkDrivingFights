# Drunk Driving Fights

A fast-paced, arcade-style multiplayer car-combat game. Drive a rocket-armed car
around the arena, blow up your friends, and be the last one standing.

## ▶ Play

**Download for Windows:** https://popanda.itch.io/drunk-driving-fights

Grab the build, unzip it, and run the game — no installation needed. Bring some
friends and play online.
